Privacy

Your slides are not uploaded

SlideFit is a static page. Choosing a .pptx reads it with the browser’s file API and JSZip, which is shipped with this site. Parsing, layout matching, and the new file are done in JavaScript on that page. There is no SlideFit account and no backend waiting for the deck.

What can leave the machine

  • The page itself. Your browser requests HTML, CSS, fonts, and scripts from wherever this site is hosted (GitHub Pages, if that is where you opened it). Those requests do not include your PowerPoint.
  • Fonts. Fraunces and Outfit are files on this site, licensed under the SIL Open Font License. They are not loaded from a third-party font host.
  • PayPal, if you pay. The PayPal Smart Buttons script is loaded from paypal.com only when config.js has a real client id. PayPal receives the checkout, not the deck. Until that id is set, the page does not load PayPal and only offers a clearly labeled local preview of the unlock.

What stays in the browser

Pro status is written to localStorage on this origin. A one-deck unlock stores a hash of the file bytes. A monthly unlock stores an expiry about 30 days out. SlideFit does not check that with a server. Clearing site data removes it. That is an honesty system, and the pricing section says so.

Samples

The Northwind and Harbor sample decks are fetched from this same site when you click the sample buttons. They are demo files, not your content.
