Privacy

Your slides are not uploaded

SlideFit is a static page. Choosing a .pptx reads it with the browser’s file API and JSZip, which is shipped with this site. Parsing, layout matching, and the new file are done in JavaScript on that page. There is no SlideFit account and no backend waiting for the deck.

What can leave the machine

  • The page itself. Your browser requests HTML, CSS, fonts, and scripts from wherever this site is hosted (GitHub Pages, if that is where you opened it). Those requests do not include your PowerPoint.
  • Fonts. Fraunces and Outfit are files on this site, licensed under the SIL Open Font License. They are not loaded from a third-party font host.
  • PayPal, if you pay. The payment happens on PayPal. PayPal takes the $5 or $12 one-time payment. It does not receive the deck. SlideFit stores only the PayPal order id, and only in this browser.

What stays in the browser

After a payment, or after you restore an order id, this site writes that order id and the purchase time to localStorage. The deck is not part of that record. $5 unlocks unlimited conversions for 24 hours. A $12 pass lasts 30 days. Neither auto-renews. SlideFit has no license server, so it cannot ask PayPal to confirm an id you type into Restore. If this browser already saved the purchase, Restore uses that product and the time still left. If it did not, Restore grants only a 24-hour pass. A full restore of a 30-day pass needs the same browser, or email nidhi69n@gmail.com with the order id. Clearing site data removes the order id.

Samples

The Northwind and Harbor sample decks are fetched from this same site when you click the sample buttons. They are demo files, not your content.
