Apply a template to an existing PowerPoint

You have a finished deck in the old theme, and a company template that marketing actually wants people to use. Applying that template is not the same as changing a font. The template is a slide master, a set of layouts, and a colour theme. The deck is the words and pictures sitting on a different master. This page is the practical version of that job.

What you need

  • The existing deck, saved as .pptx. If it is an old .ppt, open it once and save as PowerPoint Presentation.
  • The company template as .pptx or .potx. A blank deck that already uses the master is enough. You do not need a .potx specifically.
  • A browser. SlideFit does not install, and it does not upload either file.

The manual way, so you know what “done” looks like

In PowerPoint you can start from the template and use Home → New Slide → Reuse Slides, then pick the old deck. The slides arrive with their original formatting. You then select them and choose Reset, or pick a layout from the Layout gallery, and fix whatever broke. That works. It is also one slide at a time, and Reset often throws text into the wrong placeholder when the old file never used placeholders.

Copying the master the other direction (Design → browse for a theme) only works cleanly when the source slides were built on standard layouts. A deck made of loose text boxes ignores the new master until someone rebuilds it.

The SlideFit way

  1. Open SlideFit.
  2. Drop the existing deck on the left and the company template on the right. The two sample files are there if you want to see a conversion before you use a real deck.
  3. Choose Fit slides. The preview lists each source slide and the layout it landed on: Title Slide, Section Header, Title and Content, or Picture with Caption.
  4. Download the new .pptx and open it in PowerPoint or LibreOffice. The original files are untouched.

Check these after you open the file

  • Titles that were typed into a random text box may have been treated as the title. Skim the first line of each slide.
  • A picture is fitted inside the picture placeholder. If the template’s caption area is short, a long caption can overflow. Shrink the font or edit the layout once, not on every slide.
  • Charts, SmartArt, and animations are not copied. Inline formatting — bold, colour, and links — is not kept. If a slide was only a chart, you will get the title and a note that the chart was skipped. Paste the chart back from the original.
  • Wide tables use the body area of Title and Content. Column widths are even. Merge cells are not preserved.
