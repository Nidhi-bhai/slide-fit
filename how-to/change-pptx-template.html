Guide

Change a PPTX template and keep the words

A “template” in PowerPoint is easy to confuse with a theme colour. The file people hand you — often a .potx, sometimes just a .pptx named Template — contains a slide master, slide layouts (Title Slide, Title and Content, Section Header, and the rest), and a theme of fonts and colours. Changing the template means moving your content onto that master. Recolouring a shape on one slide is a different, smaller task.

Save a template you can actually use

If the brand file opens as a single title slide that says the company name, that is enough. SlideFit throws away content slides from the template and keeps the master, the layouts, and the theme. If you only have a .potx, you can drop that file directly, or use File → Save As → PowerPoint Presentation (.pptx) and drop the copy. Do not paste a screenshot of the template. The tool needs the layouts, not a picture of them.

Check the template once before you convert a long deck. View → Slide Master. You want a real title placeholder and a body placeholder, not a flattened JPEG of a slide. If the “template” is a picture filling the slide, there is nothing to reflow into.

Change the template with SlideFit

  1. Put the old deck on the left of SlideFit and the template on the right.
  2. Fit slides. Read the mapping line under the preview. “Pipeline health → Title and Content” means the bullets were written into that layout’s body placeholder, so they pick up the template’s bullet font and colour.
  3. Download. The new package still contains the template’s theme1.xml, slide master, and layouts. Text is marked to use the theme’s major and minor fonts (+mj-lt and +mn-lt) and the theme text colour, so a later edit to the theme follows through.

What will look different on purpose

Slide size follows the template. A 4:3 source on a 16:9 template is reflowed, not stretched like a photo. A logo or coloured bar that lives on the master shows up on every new slide, because those shapes are not placeholders. The sample Harbor template includes a teal bar and the words “HARBOR & CO.” so you can see this immediately.

Footers, dates, and slide numbers stay with the layout. SlideFit does not copy the old deck’s footer text over them.

What will not change by itself

  • Speaker notes are not copied.
  • Slide transitions and animations are not copied.
  • Embedded fonts in the old deck are not required. The new file asks for the template’s fonts. If a teammate does not have Georgia or whatever the theme names, PowerPoint substitutes, the same way it would with the template itself.

If you need the notes, copy them from the original after the visual pass. Notes are text; the painful part was the master.
