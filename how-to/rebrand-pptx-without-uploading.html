Rebrand a PowerPoint without uploading it

A lot of “free PPT template” sites want the file. That is a bad trade when the deck is a client’s numbers, an unreleased product, or anything your security team would not paste into a random form. Rebranding does not require a server. The template and the content are both files you already have. The work is XML inside a zip, and a browser can unzip.

What stays on the machine

SlideFit reads the files you pick with the file input. JSZip, included in the page, unzips them. The script builds a new pptx and hands it back as a download. There is no fetch of your deck. You can confirm that in the browser’s network panel: fitting the slides does not add a request whose body is the PowerPoint. The only requests are for the page, its scripts, and — if you click them — the public sample files.

PayPal is the exception, and only if a real client id is set in config.js. That script talks to PayPal about the $5 or $12 charge. It does not receive the presentation. While the client id is still the placeholder, PayPal is not loaded at all.

A rebrand pass that respects that boundary

  1. Keep the company template in your own drive. Do not upload it to a third-party converter either; masters sometimes contain unreleased campaign lines in the footer.
  2. Open SlideFit. Drop the old deck and the template. Fit.
  3. Use the preview to see that titles, bullets, pictures, and tables survived. The preview is drawn in the page from the same extraction. It is not a screenshot service.
  4. Download and open the file locally in PowerPoint or LibreOffice.
  5. If the deck is longer than five slides, the free file stops there and adds a watermark slide named “SlideFit free watermark”. Pay for that deck, or use the local preview unlock while payments are unconfigured, then fit again. The second download replaces the short file. Nothing about that step uploads the slides.

What “unlock” does and does not mean

The Pro flag is written to localStorage for this site. It is not a cryptographic license. The page says so next to the price. Use it as a convenience for a real PayPal button, or as a way to try the full sample conversion. Do not describe it to a customer as a server-enforced subscription unless you add a server. The privacy property — the deck is not uploaded — does not depend on that flag.

When you still should not use a browser tool

If policy forbids opening the file in a browser at all, even locally, use PowerPoint on the desktop: start from the template, Reuse Slides, then reset layouts. SlideFit is for the case where the browser is allowed and a third-party upload is not.
